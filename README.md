# Food Lover Restaurant

Food Lover is a restaurant website built with HTML and CSS. The idea behind this project is to create a simple, attractive place where visitors can explore the restaurant, discover its menu, check special offers, and find contact information.

I focused on making the website visually appealing and easy to navigate, with a warm color palette, food photography, and a responsive layout that works on different screen sizes.

## Features

- **Home Page**: A welcoming landing page with restaurant branding and a booking button.
- **About Us**: A short introduction to the restaurant and its story.
- **Special Offers**: A section highlighting selected meals at discounted prices.
- **Food Menu**: A collection of dishes with descriptions and prices.
- **Opening Hours**: Information about breakfast, lunch, dinner, and desserts.
- **Food Gallery**: A collection of images showcasing the restaurant's food.
- **Contact Section**: Restaurant details and a form for visitors to write a message.
- **Responsive Design**: Layout adjustments for desktop, tablet, and mobile screens.
- **Smooth Navigation**: Navigation links that move visitors between sections of the page.

## Built With

- HTML5
- CSS3
- Flexbox and CSS Grid
- Google Fonts - Quicksand

## Getting Started

You don't need to install any packages or set up a development environment to run this project.

1. Open `index.html` in your browser.

That's it! The website should be ready to explore.

You can also open the project in VS Code and use the Live Server extension while developing.

## Customization

Feel free to make the website your own. You can:

- Change the restaurant name, descriptions, and menu items in `index.html`.
- Update colors, spacing, and layouts in `style.css`.
- Replace the food photos with your own images.
- Add more dishes, special offers, or gallery images.
- Connect the contact form to a backend to receive actual messages.
- Integrate a reservation system to allow customers to book tables online.

## Current Limitations

This is a frontend project, so some features are only visual at the moment.

- The contact form does not send messages to a server.
- The booking button links to the contact section rather than creating a reservation.
- Menu items and prices are static and cannot be updated dynamically.

These features can be implemented later with JavaScript and a backend if the project is extended.
